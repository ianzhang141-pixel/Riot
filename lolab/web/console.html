1 数据目录

数据存在哪个文件夹。就是你现有网站里放 riot_secret.json 的那个 data 文件夹。

2 Riot API Key

去 Riot Developer Portal 登录后，页面上那串 RGAPI- 开头的 Development Key，整段复制粘贴进来。 Development Key 每 24 小时过期，过期了就回来重新粘一次。 Key 只会写进你自己电脑上的 riot_secret.json，不会发给任何人，页面上也只显示遮蔽形式。

3 同步比赛（含 Timeline）

填一个 Riot ID，自动走完：账号 → PUUID → 最近 N 场 → 逐场下载 Match 和 Timeline。 Timeline 是另一个独立接口，很多实现只抓了 Match 没抓 Timeline —— 这里两个都会抓。
