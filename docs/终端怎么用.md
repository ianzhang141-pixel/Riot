# 终端怎么用（写给完全没用过的人）

这一篇不讲项目，只讲**终端这个黑框框到底怎么操作**。
看完这篇，再去看 [使用说明.md](使用说明.md)。

---

## 一、终端是什么

终端是一个**你打字、电脑照做**的窗口。它不会自己动，你不敲它就一直等着。

它不危险。本文里的每一条命令都只做三件事之一：进文件夹、下载文件、启动一个本地网页。
**没有任何一条会删东西。**

---

## 二、打开终端

**办法一（最快）：**

1. 按 `Command + 空格`（Command 是空格键旁边那个 ⌘ 键）
2. 屏幕中间出现一个搜索框
3. 输入 `Terminal`
4. 按 `回车`（Return ⏎）

**办法二：**

访达 → 左边栏「应用程序」→ 拉到底找到「实用工具」文件夹 → 双击「终端」

---

## 三、打开后你会看到什么

一个白色或黑色的窗口，里面有一两行字，最后一行长得像这样：

```
你的名字@Mac ~ %
```

或者结尾是 `$` 而不是 `%`（两个都正常，取决于系统版本）。

**这一行叫「提示符」。** 它的意思是「我准备好了，你说」。
后面有个闪烁的小方块，那是光标，你打的字会出现在那里。

> ⚠️ **重要：后面所有命令，你都不需要自己打字，复制粘贴就行。**
> 自己打很容易打错一个字符，然后卡住半天。

---

## 四、怎么执行一条命令（这是最关键的一节）

以本文档里的任何一个灰色代码块为例，比如：

```bash
cd ~/lolab-tools
```

**完整操作是这四步：**

1. **复制** —— 用鼠标选中那行字（不要选中 ```bash 那部分），按 `Command + C`
2. **点一下终端窗口** —— 让它变成当前窗口（标题栏颜色会变深）
3. **粘贴** —— 按 `Command + V`。这行字会出现在光标位置
4. **按 `回车`** —— 这一步最容易忘。**不按回车，命令不会执行。**

按下回车之后，终端会：
- 输出一些文字（可能几行，也可能几十行）
- 然后**再次出现提示符** `你的名字@Mac xxx %`

**再次看到提示符 = 这条命令跑完了，可以敲下一条。**

## 五、五种常见情况，怎么分辨

### 情况 1：成功了

输出了一些字，然后出现新的提示符。没有 `error`、`fatal`、`command not found` 这些词。
→ **继续下一步。**

### 情况 2：看起来卡住了，光标在闪，什么都不动

**这通常是正常的**，说明它正在下载或者正在运行。
下载 20 场比赛要一分钟左右，期间可能长时间没有新输出。

→ **不要按任何键，等着。** 特别不要反复按回车。

### 情况 3：出现 `command not found`

```
zsh: command not found: git
```

意思是「这个程序你电脑上没装」。本文档里遇到的话，往下看第七节有解决办法。

### 情况 4：出现 `No such file or directory`

```
cd: no such file or directory: /Users/xxx/lolab-tools
```

意思是「这个文件夹不存在」。通常是前一步没做成功，或者路径打错了。
→ **回到上一步重做。**

### 情况 5：一直不出现新的提示符，而且是你启动的服务器

比如你运行了 `python3 -m lolab serve`，看到：

```
控制台已启动：http://127.0.0.1:8010
```

然后就不动了 —— **这是对的**。服务器就是要一直挂着。
这时候提示符不会回来，直到你按 `Control + C` 停掉它。

## 六、必须记住的三个快捷键

| 快捷键 | 什么时候用 |
| --- | --- |
| `Control + C` | **停止正在运行的东西。**卡住了、想退出服务器，都按它。Control 不是 Command |
| `↑`（上箭头） | 调出你上一条命令，不用重新粘贴 |
| `Command + V` | 粘贴 |

其他好用的（可选）：

| 快捷键 | 作用 |
| --- | --- |
| `Control + U` | 把当前这行你打的字全部清空，重来 |
| `Control + A` / `Control + E` | 光标跳到行首 / 行尾 |
| `Command + T` | 开一个新标签（想同时跑两个东西时用） |
| `Command + K` | 清屏（输出太多看着乱时用） |

## 七、你会遇到的命令，分别是什么意思

### `cd ~`

`cd` = change directory（换文件夹）。`~` 代表你的个人文件夹。
**这条命令的意思是：回到我的个人文件夹。**

执行后提示符里的路径部分会变，比如从 `~/Documents` 变成 `~`。

### `git clone https://github.com/...`

从 GitHub 上把代码下载到当前文件夹。

**只需要做一次。** 做过之后，文件已经在你电脑上了。

如果报 `command not found: git`：

1. 执行 `xcode-select --install`
2. 会弹出一个窗口问你要不要安装，点「安装」
3. 等它装完（几分钟到十几分钟，取决于网速）
4. 装完回来重新执行 `git clone` 那条

如果报 `already exists and is not an empty directory`（文件夹已存在）：
说明你之前已经下载过了。**跳过 clone，直接执行下一条命令就行。**

### `git checkout 分支名`

切换到某个版本。我们的代码在 `claude/lol-huya-video-download-akna78` 这个分支上。

成功的话会显示 `Switched to a new branch ...` 或 `Already on ...`。

### `python3 -m lolab serve`

启动本地控制台。Mac 自带 python3，不需要安装。

成功的话会显示一个框，里面有 `http://127.0.0.1:8010`。
**然后终端会一直挂着不动，这是对的，别关窗口。**

### `&&`

把两条命令连起来：「前一条成功了，就接着做后一条」。

所以 `cd ~/lolab-tools && python3 -m lolab serve` 的意思是
「先进到 lolab-tools 文件夹，成功的话就启动控制台」。

## 八、完整流程演练

### 第一次用（只做一次）

打开终端，粘贴这一整段，按回车：

```bash
cd ~ && git clone https://github.com/ianzhang141-pixel/Riot.git lolab-tools && cd lolab-tools && git checkout claude/lol-huya-video-download-akna78
```

**正常会看到**（数字会不一样）：

```
Cloning into 'lolab-tools'...
remote: Enumerating objects: 45, done.
remote: Total 45 (delta 12), reused 45 (delta 12)
Receiving objects: 100% (45/45), 38.21 KiB | 2.10 MiB/s, done.
Switched to a new branch 'claude/lol-huya-video-download-akna78'
```

看到最后那行 `Switched to a new branch` 就成了。

### 每次要用（包括第一次）

```bash
cd ~/lolab-tools && python3 -m lolab serve
```

**正常会看到：**

```
  ┌──────────────────────────────────────────────┐
  │  控制台已启动：http://127.0.0.1:8010        │
  └──────────────────────────────────────────────┘

  数据目录：/Users/你的名字/lolab-tools/data
  在 Chrome 里打开上面那个地址，接下来全在网页上点。
  要停止：回到这个窗口按 Control + C。
```

然后：

1. **把终端窗口留着别关**（可以缩小，但不能关）
2. 打开 Chrome
3. 地址栏输入 `127.0.0.1:8010`，回车
4. **剩下的全在网页上点，不用再碰终端了**

> 上面写的「数据目录」如果不对不用管，在网页上点「自动查找」改就行。

### 用完了怎么关

1. 点一下终端窗口
2. 按 `Control + C`
3. 看到 `已停止。` 和新的提示符
4. 现在可以关窗口了

## 九、下次要用怎么办

**不用重新 clone。** 打开终端，粘贴这一条就行：

```bash
cd ~/lolab-tools && python3 -m lolab serve
```

按 `↑` 上箭头也能把上次的命令调出来。

## 十、卡住了发什么给 AI

**把终端窗口里的字全选复制发过来：**

1. 点一下终端窗口
2. 按 `Command + A`（全选）
3. 按 `Command + C`（复制）
4. 粘贴给 AI

网页上的问题就直接截图。

**不要只说「报错了」或只发最后一行** —— 中间的内容才是能定位问题的。

⚠️ 发之前扫一眼有没有 `RGAPI-` 开头的一长串字符。那是你的 API Key，
**不要发给任何人，包括 AI。** 这个工具的输出不会打印你的完整 Key，
但养成检查的习惯没坏处。
