# lolab 使用说明（Mac，零基础版）

这个工具箱只做一件事：**先把真实数据验证清楚，再谈胜率模型。**

它不需要安装任何东西，Mac 自带的 `python3` 就能跑。
它也不会改动你现在跑在 `http://127.0.0.1:8000` 的那个网站，两者互不干扰。

---

## 第 0 步：把代码拿到 Mac 上

1. 打开「访达」(Finder)。
2. 按 `Command + Shift + H` 回到你的个人文件夹。
3. 打开「终端」(Terminal)：按 `Command + 空格`，输入 `Terminal`，回车。
4. 在终端里粘贴下面这一行，然后回车：

```bash
cd ~ && git clone https://github.com/ianzhang141-pixel/Riot.git lolab-tools && cd lolab-tools
```

**正常情况下你会看到：** 一堆 `Cloning into ...` 之类的文字，最后终端提示符变成
`lolab-tools %` 之类的样子。

> 如果提示 `git: command not found`，先执行 `xcode-select --install`，
> 弹窗点「安装」，装完再回来重跑上面那一行。

以后每次要用这个工具，**都必须先执行这一行进到正确的文件夹**：

```bash
cd ~/lolab-tools
```

---

## 第 1 步：告诉它你的 data 目录在哪

你现在的项目里有一个 `data` 文件夹（网站说 Key 存在 `data/riot_secret.json`）。
把它的完整路径找出来：

1. 在「访达」里找到你项目的 `data` 文件夹。
2. 右键点它，按住 `Option` 键，菜单里会出现「拷贝“data”为路径名称」，点它。
3. 现在路径已经在剪贴板里了。

在终端里执行（`--data` 后面按 `Command + V` 粘贴刚才拷的路径，**两边要加双引号**）：

```bash
python3 -m lolab where --data "粘贴到这里"
```

**正常情况下你会看到：**

```
data 目录：/Users/你的名字/你的项目/data
存在：是
扫描到 23 场比赛。
  · KR_8368663855
  · KR_8368626054
  ...
```

如果「扫描到 0 场比赛」，说明 Match/Timeline 并没有以 JSON 形式存在这个目录里，
把上面这段完整输出发给 AI。

> 嫌每次都要粘贴路径太麻烦？执行一次下面这行，之后所有命令都可以省略 `--data`：
> ```bash
> export LOLAB_DATA="你的data路径"
> ```
> 注意：这个设置**只在当前终端窗口里有效**，关掉窗口就没了。

## 第 2 步：检查 Timeline 到底有没有真的存在本机

这是当前最高优先级的任务。以 `KR_8368663855` 为例：

```bash
python3 -m lolab check KR_8368663855 --data "你的data路径"
```

**如果数据是完整的，你会看到：**

```
✅ Match JSON
      来源：/Users/.../data/matches/KR_8368663855.json
      版本 16.17.810.4348 · Queue 420 · 时长 31.0 分钟 · 10 名玩家
✅ Timeline JSON
      来源：/Users/.../data/timelines/KR_8368663855.timeline.json

  —— Timeline 内容 ——
      帧数：32  帧间隔：60000 毫秒  覆盖到：31.0 分钟
      ✅ 每帧 10 名玩家
      ✅ 每帧 x/y 坐标
      ✅ 关键字段 level / xp / totalGold / currentGold / cs / jungleCs / position

  —— 事件（共 1893 条）——
      ITEM_PURCHASED                   312
      CHAMPION_KILL                     41
      ...

结论：✅ 数据完整，可以进入下一步（生成 State / 做胜率模型）。
```

**如果 Timeline 没下载过，你会看到：**

```
❌ Timeline JSON
结论：❌ 有问题，先解决下面这些：
      · 没有找到 Timeline JSON —— 这就是当前最大的技术断点
      建议执行：python3 -m lolab fetch KR_8368663855
```

那就照着做（下一步）。

---

## 第 3 步：补下载缺失的 Timeline

```bash
python3 -m lolab fetch KR_8368663855 --data "你的data路径"
```

它会自己从 `data/riot_secret.json` 里读你已经保存过的 Riot API Key，
**你不需要、也不应该把 Key 发给任何人**。

- Match 存到 `data/matches/KR_8368663855.json`
- Timeline 存到 `data/timelines/KR_8368663855.timeline.json`
- 下载完会自动再跑一次第 2 步的检查

**如果看到 `HTTP 403：API Key 无效或已过期`：**
Development Key 24 小时就过期。去 Riot Developer Portal 重新生成一个，
在你网站的「Riot API」页面重新保存一次，再跑这条命令。

---

## 第 4 步：把 Timeline 转成分钟级 State

先更新一次装备价格表（只需要做一次，用来把装备栏换算成「装备价值」）：

```bash
python3 -m lolab items --data "你的data路径"
```

然后生成 State：

```bash
python3 -m lolab state KR_8368663855 --minute 10 --data "你的data路径"
```

**正常情况下你会看到** 一个 JSON 被写到 `data/states/`，
接着终端里直接打印出第 10 分钟的完整局势：10 名玩家的等级 / 金币 / 经验 /
补刀 / 野怪 / 坐标，以及双方的塔、龙、先锋、大龙和经济差。

把 `--minute 10` 改成任何数字就能看那一分钟。

---

## 第 5 步：打开调试页面，用眼睛核对数据

```bash
python3 -m lolab serve --data "你的data路径"
```

**正常情况下你会看到：**

```
调试页面已启动：http://127.0.0.1:8010
```

在 Chrome 里打开 `http://127.0.0.1:8010`，点任意一场比赛，你会看到：

- 顶部一个时间滑块，拖动就能在整场比赛里前后移动
- 10 名玩家逐帧的等级 / 总金币 / 现金 / 经验 / CS / 野怪 / 装备价值 / KDA / 眼 / 坐标
- 一张小地图，把 Timeline 里的 x/y 画成 10 个点（**位置对得上就说明坐标解析正确**）
- 这一分钟内发生的每一条事件
- 右下角的数据完整性结论

要停止它：回到终端窗口按 `Control + C`。

> 这个页面跑在 **8010** 端口，和你原来的 8000 网站互不影响，可以同时开着。

**这一步是整个流程的关卡。** 只有你亲眼确认这些数字是对的，
才应该往下做 V(s) 胜率模型。看到任何一格数字不对劲，先截图发给 AI。

## 第 6 步（可选）：虎牙录像下载

原来手工「DevTools 找 m3u8 + 手敲 ffmpeg」的流程，现在一条命令：

```bash
python3 -m lolab huya "https://v.huya.com/play/录像编号.html" --data "你的data路径"
```

它会自动解析 m3u8、自动挑最高画质、自动命名，存到 `data/videos/`，
并把每次下载记进 `data/videos/index.json`（这就是「录像库」）。

**批量下载**（不用开一堆终端标签）：

```bash
python3 -m lolab huya "地址1" "地址2" "地址3" --workers 3 --data "你的data路径"
```

或者把地址一行一个写进一个文本文件，然后：

```bash
python3 -m lolab huya --file ~/Downloads/录像列表.txt --workers 3 --data "你的data路径"
```

**只想先看看有哪些画质、不下载：** 加 `--list`。

**如果自动解析失败**（虎牙随时可能改页面结构），
你原来那条已经验证可用的路子永远还在——照旧用 DevTools 复制 m3u8，然后：

```bash
python3 -m lolab huya --m3u8 "完整m3u8地址" --name 想要的文件名 --data "你的data路径"
```

前提是 FFmpeg 已经装好（你已经装过 `ffmpeg 9.0.1`，没问题）。

## 出错了要发什么给 AI

**把终端里从你输入命令那一行开始、到最后一行为止的全部文字复制发过来。**
在终端里选中文字后按 `Command + C` 即可。

不要只发「报错了」或者只发最后一行，中间的内容才是有用的。

**永远不要**把 `RGAPI-` 开头的 API Key 贴给任何人。
这个工具箱的所有输出都不会打印你的 Key。
