# 使用说明（Mac，零基础版）

**你只需要在终端敲一条命令，其余全部在浏览器里点。**

这个工具不需要安装任何东西，Mac 自带的 `python3` 就能跑。
它跑在 **8010** 端口，和你现有的 8000 网站互不干扰，可以同时开着。

---

## 第 0 步：把工具拿到 Mac 上（只做一次）

1. 按 `Command + 空格`，输入 `Terminal`，回车，打开终端。
2. 复制下面这一整段，粘贴进终端，按回车：

```bash
cd ~ && git clone https://github.com/ianzhang141-pixel/Riot.git lolab-tools && cd lolab-tools && git checkout claude/lol-huya-video-download-akna78
```

**正常会看到：** 一堆 `Cloning into ...`，最后一行类似
`Switched to a new branch 'claude/lol-huya-video-download-akna78'`。

> 如果提示 `git: command not found`：执行 `xcode-select --install`，
> 弹窗点「安装」，装完再回来重跑上面那一段。

---

## 第 1 步：启动控制台（每次要用都做这一步）

```bash
cd ~/lolab-tools && python3 -m lolab serve
```

**正常会看到：**

```
  ┌──────────────────────────────────────────────┐
  │  控制台已启动：http://127.0.0.1:8010        │
  └──────────────────────────────────────────────┘
```

在 Chrome 里打开 **http://127.0.0.1:8010**。

> **这个终端窗口不要关**，关了控制台就停了。
> 要停止：回到终端窗口按 `Control + C`。

---

## 第 2 步：在网页上点完 1 → 2 → 3

页面上有三个带编号的方块，按顺序做完就行。编号变绿 ✅ 就是这一步完成了。

### 1️⃣ 数据目录

告诉它数据存在哪个文件夹 —— 就是你现有网站放 `riot_secret.json` 的那个 `data` 文件夹。

**最省事的办法：点「自动查找」**，它会扫描你的个人文件夹，把找到的候选目录列出来，
带 `riot_secret.json` 的那个排在最前面。点旁边的「用这个」即可。

找不到就手动填：在访达里找到那个 `data` 文件夹，**直接用鼠标拖进终端窗口**，
路径会自动出现，复制粘贴到输入框里。

### 2️⃣ Riot API Key（你问的「重新上传 API」就是这一步）

1. 点页面上的 **Riot Developer Portal** 链接，用你的 Riot 账号登录。
2. 页面上有一串 `RGAPI-` 开头的 **Development API Key**，整段复制。
3. 粘贴进输入框，点 **保存**。
4. 点 **验证是否有效** —— 看到「✅ Key 有效，KR 大区连接正常」就成了。

关于安全：Key 只写进你自己电脑上的 `riot_secret.json`（权限设为只有你能读），
不上传任何地方。页面上永远只显示遮蔽形式，例如 `RGAPI-abc…90ab`。
**不要把完整 Key 贴给任何人，包括 AI。**

> **Development Key 每 24 小时就过期。** 之后看到 `HTTP 403：API Key 无效或已过期`，
> 就回 Portal 重新生成一个，回到这一步重新粘一次。这是正常的，不是出故障。

### 3️⃣ 同步比赛（含 Timeline）

填一个 Riot ID（例如 `JUGKING#Kr`），大区选 `asia`，场数填 20，Queue 填 420，
点 **开始同步**。

下面会实时滚动日志，能看到它在做什么：

```
查询 Riot ID：JUGKING#Kr（asia）
  ✅ PUUID：xxxxxxxxxxxx…（这才是稳定身份，改名也不变）
拉取最近 20 场（Queue 420）
  ✅ 拿到 20 个 Match ID
  ✅ KR_8368663855 match → KR_8368663855.json
  ✅ KR_8368663855 timeline → KR_8368663855.timeline.json
  ...
完成：新下载 20 场，已存在跳过 0 场，失败 0 场。
现在数据目录里共 20 场，其中 20 场有 Timeline。
```

**这一步是关键。** `Timeline` 是 Riot 的**另一个独立接口** ——
很多实现只抓了 Match 没抓 Timeline，这大概率就是你现在缺数据的原因。
这里两个都会抓。

## 第 3 步：核对数据是不是真的对

页面最下面是「比赛库」，每一场都标着 Match 和 Timeline 齐不齐：

| Match ID | Match | Timeline | |
| --- | --- | --- | --- |
| KR_8368663855 | ✅ | ✅ | 逐分钟核对 → |
| KR_8368626054 | ✅ | ❌ 缺 | 补下载 |

- 缺 Timeline 的，点「补下载」，单独补这一场。
- 齐了的，点「逐分钟核对」，进入调试页。

调试页里有：

- 顶部时间滑块，拖动就能在整场比赛里前后移动
- 10 名玩家逐帧的等级 / 总金币 / 现金 / 经验 / CS / 野怪 / 装备价值 / KDA / 眼 / 坐标
- **一张小地图**，把 Timeline 里的 x/y 画成 10 个点
- 这一分钟内发生的每一条事件（带中文解释，例如「Cho'gath 击杀 LeeSin（助攻 Ahri）」）
- 右下角的数据完整性结论

**怎么算「核对过了」：**

1. 小地图上 10 个点的位置合理吗？开局都在各自基地附近，中期散开在三路和野区。
   位置对得上，说明**坐标解析正确**。
2. 金币和等级随时间**单调上涨**吗？中途突然归零或暴跌就是有问题。
3. 打野的「野怪」列有数字、「CS」列接近 0；对线位反过来。
4. 击杀事件的时间点，和比分变化对得上吗？

这四条都合理，数据就可以信。**只有到这一步，才该开始做 V(s) 胜率模型。**

有任何一格不对劲，截图发给 AI。

## 顺带：虎牙录像下载

装备价格表在控制台上有按钮，虎牙下载目前还在终端里（网页版下一轮再做）：

```bash
cd ~/lolab-tools
python3 -m lolab huya "https://v.huya.com/play/录像编号.html"
```

自动解析 m3u8、自动挑最高画质、自动命名，存到 `data/videos/`。

批量（不用开一堆终端标签）：

```bash
python3 -m lolab huya "地址1" "地址2" "地址3" --workers 3
```

自动解析失败时（虎牙随时可能改页面结构），你原来那条已验证可用的路子永远还在：

```bash
python3 -m lolab huya --m3u8 "从DevTools复制的完整m3u8地址" --name 想要的文件名
```

## 出问题了怎么办

**把终端里从你输入命令那一行开始、到最后一行为止的全部文字复制发给 AI。**
在终端里选中文字后按 `Command + C`。网页上报错的话，直接截图。

不要只发「报错了」或只发最后一行 —— 中间的内容才是有用的。

**永远不要**把 `RGAPI-` 开头的完整 Key 贴给任何人。
这个工具的所有输出都不会打印你的完整 Key。

### 常见情况

| 现象 | 原因 / 处理 |
| --- | --- |
| `HTTP 403：API Key 无效或已过期` | Development Key 24 小时过期了，回 Portal 重新生成，回第 2️⃣ 步重新粘 |
| `HTTP 404` 查不到 Riot ID | 名字或标签拼错了。注意大写 `I` 和小写 `l` 极易混淆 |
| `HTTP 429` | 触发限流，工具会自动等待重试，不用管 |
| 「比赛库」是空的，但发现了数据库文件 | 你的数据可能存在 SQLite 里而不是 JSON，把页面截图发给 AI |
| 浏览器打不开 8010 | 终端窗口是不是关了？回第 1 步重新启动 |

## 备用：全部用终端做

不想用网页也可以，所有功能都有对应命令（`--data` 后面填你的 data 路径）：

```bash
python3 -m lolab where  --data "你的data路径"        # 认的是哪个目录、扫到几场
python3 -m lolab check  KR_8368663855                # Timeline 完整性检查
python3 -m lolab fetch  KR_8368663855                # 补下载单场
python3 -m lolab items                               # 更新装备价格表
python3 -m lolab state  KR_8368663855 --minute 10    # 打印第 10 分钟的完整局势
```

| 快捷键 | 作用 |

| `Control + C` | 停止正在运行的命令（用来关控制台） |

| `Control + U` / `Control + K` | 删掉光标左边 / 右边的内容 |
| `Control + A` / `Control + E` | 跳到行首 / 行尾 |
