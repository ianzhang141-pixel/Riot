## 实际验收清单

至少选十局可追溯真实 LPL，保留各自完整原始响应。覆盖胜/负、至少多个系列赛、不同比赛长度；有条件时跨日期和版本采样。当前门槛为十局，报告同时统计系列赛数；若研究要求十个 BO 系列赛，应另增 seriesCount 门槛。

逐局要求：稳定的来源 ID；正确的 BO 系列赛和局号；两队稳定 ID 与蓝红方关系；十名选手稳定 ID 与英雄；完整采样时间和版本；经济/经验/等级/补刀；地图位置；装备事件；击杀和资源事件；逐局质量检查。必须人工比对至少部分赛后比分、时间点和来源页面，不能只填一个 league=LPL 标签。

跨局/跨日要求：重复发现结果是否稳定、赛程修订能否更新、失败恢复是否遗漏、重复事件规则是否适用、历史能追溯到何时、实际限速是多少。保存接口条款/授权记录，分别确认长期存储、模型分析与商业使用；当前软件门槛只强制前两项 approved，商业用途仍需单独确认。

官方 Riot 文档说明某些零值可能省略。本系统按用户要求仍将未返回字段保存为 null，不擅自推断成 0。因此真实数据可能触发较多缺失报告；后续如增加“该来源明确省略零”的适配规则，应单独记录推断依据和版本，不能改动原始响应。
